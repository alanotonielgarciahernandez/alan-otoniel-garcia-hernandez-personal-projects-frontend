# Information
Started in June 26 of 2024, The Personal Projects web application was developed after watching 36 over 55 hours of a ReactJS course on Udemy.  
With the need to build a portfolio to increase my chances of getting a job, I made the decision to pause the course and work on this project to build my portfolio and to test and expand my knowledge and skill.

## How has this project helped me build my portfolio?
The Personal Projects web application source code shows my understanding and skill in action by using most of the tools provided by the technology used and by implementing the project with systems using different technologies as currently used by leading companies.
In addition, using this project to expose my work and make it understandable to all the public helps to showcase my knowledge.

## How has this project helped me test and expand my knowledge?
Trying to replicate an application like GitHub made me learn how it works on the inside, how long does it take to replicate the same application only with the main functionalities and how long would it take to add extra functionalities like codespaces.

## How has this project helped to test and expand my skills?
Working in an application all by myself without following steps from a course or tutorial made me train my logical process.

I was interested in how GitHub works to bring data from Git repositories to a website where users can inspect many projects in an accessible way.
Also, making a copy of an existing software helps to skip the search for ideas process to start directly with the development process.

# How to use

## Requirements
[ NodeJS ]( https://nodejs.org/ ) and [ Yarn ]( https://yarnpkg.com/ ) are required to start working in this project.  
Install all the node modules by opening a shell and run the following command inside the project folder:
```sh
yarn install
```

## Connect with back-end
This project requires the personal-projects-backend to get projects data. You need to set in a ".env" back-end URL as below:
```js
VITE_API_URL='<backend-url>'
```
When using docker you will need to set the environment variable as below:
```js
API_URL='<backend-url>'
```

## Build the project
Open a shell and run the command below to build the project to the production version.
```sh
yarn build
```

# Functions
This project provides the same main functions as GitHub.

## List project files
Navigate through projects repository tree.

## Jump between commits.
Watch the projects change history and inspect the differences between its previous state.

## Issues tracking.
Get the status of known issues.

## Download the project at any point.
Select the point where you would like to download a project to try it on your machine.

## Preview the content of the project files.
Don't wait to download the project to study it, start reading right now the content.
